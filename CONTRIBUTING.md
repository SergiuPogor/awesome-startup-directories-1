# Contributing

Thanks for helping improve Awesome Startup Directories!

## What to add

Please suggest platforms that help founders discover, launch, or list:

- SaaS products
- AI tools
- Developer tools
- Startups and indie projects
- Open-source software

## Requirements

Before opening a pull request:

1. Confirm the website is live and the URL is correct.
2. Add a short, factual description of what the platform does.
3. Do not claim a listing is free unless you have recently verified that.
4. Do not describe a platform as a guaranteed backlink or SEO boost.
5. Avoid affiliate links, referral tracking links, and promotional spam.
6. Check that the platform is not already listed.

## Format

Add entries using this format:

| Platform name | What it's useful for | https://example.com/ |

Keep entries in the most relevant category and alphabetize within that category where practical.
